它做了什么

抖音火花需要双方每天互发消息才能延续。好友一多，逐个点开发消息就成了负担。

🕐

定时静默执行

浏览器启动后随机延迟 1–5 分钟，在后台标签页打开抖音私信，完成后自动关闭，全程不切换到前台。

🔍

自动识别火花

滚动扫描完整会话列表（含虚拟列表未渲染部分），识别火花标记与「重燃中」状态。

🎯

不会发错人

以头像指纹认人，点开会话后二次校验身份 —— 列表会因新消息随时重排。

🛡️

四重防重复

每日闸门 → 身份校验 → 读取页面聊天记录 → 失败不重试。宁可漏发，不重复打扰。

📋

名单可控

白名单强制纳入、黑名单永久排除，发送内容、间隔、单次上限均可自定义。

🔒

数据不出本机

配置与日志只存在浏览器本地，无任何外部网络请求，不收集任何信息。

安装步骤

约一分钟完成，只需做一次。

  1. 下载并解压点上方按钮下载 ZIP，解压到长期保留的目录，例如 D:\Edge扩展\douyin-spark-keeper。解压后文件夹里应能看到 manifest.json。
  2. 打开扩展管理页在 Edge 地址栏输入 edge://extensions/ 回车。
  3. 启用开发人员模式打开页面左下角的「开发人员模式」开关。
  4. 加载扩展点击「加载解压缩的扩展」，选择第 1 步解压出的、含 manifest.json 的文件夹。
  5. 固定图标并登录抖音建议把扩展图标固定到工具栏方便查看状态。确认浏览器已登录抖音网页版、能正常打开私信。
🔄
更新版本时：下载新包覆盖原目录，然后回到 edge://extensions/ 点击本扩展的「重新加载」。Edge 运行的是扩展副本，不点重新加载仍会执行旧代码。

装好即生效，无需任何配置。下次启动 Edge 时会自动执行一次。

常见问题

会给同一个人重复发消息吗？

不会。是否已发一律以页面上的实际聊天记录为准，而非本地记录 —— 只要今天你或扩展已经发过消息，就会跳过。

此外还有三道保障：自动任务每天只成功执行一次；点开会话后校验头像确认是本人；发送校验失败只记录、绝不重发。

为什么火花还是断了？

火花规则由抖音制定，通常要求双方当日均发送消息。扩展只能保证你这一侧发出，对方没回复仍可能中断。

会不会触发风控？

扩展只做和你手动操作完全一样的事：打开会话、输入文字、按回车。默认间隔 2–5 秒且每人每天仅一条，不建议调快。使用自动化操作的风险请自行评估。

我自己在刷抖音时它会乱点吗？

不会。内容脚本默认完全被动，只有收到后台任务指令时才会操作页面。

数据会上传吗？

不会。配置与日志仅保存在你的浏览器本地存储中，扩展没有任何对外通信代码，源码完全公开可审计。

抖音改版后不工作了怎么办？

识别逻辑集中在一个文件里，并支持在设置页用 JSON 覆盖，无需改代码。例如会话列表类名变了：

{ "conversationList": { "css": [".新的类名"] } }

也可以到 GitHub Issues 反馈，或直接更新到最新版本。

能在 Chrome 上用吗？

可以。扩展基于 Manifest V3，Chrome 114+ 用同样方式在 chrome://extensions/ 加载即可，但主要在 Edge 上测试。
